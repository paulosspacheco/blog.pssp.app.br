# Comunicação Não-Conflitiva

## Sigla: R.F.E.P.

    R = Reconhecer → Reconheça o feedback ou comentário

    F = Fato → Foque no que aconteceu, não na pessoa

    E = Explicar → Explique seu ponto de vista de forma neutra

    P = Pedido → Faça uma pergunta ou sugira ação/ajuda

## Gatilhos rápidos por tipo de ataque

| Tipo de ataque           | Flash / Palavra-chave                                  | Como lembrar                                        |
| ------------------------ | ------------------------------------------------------ | --------------------------------------------------- |
| Crítica direta           | **R** → “Obrigado, percebi…”                           | Reconhecer e validar sem discutir                   |
| Autoritário / imposição  | **F** → “Entendi, posso fazer…”                        | Foco na execução, peça esclarecimento se necessário |
| Comparações / julgamento | **E** → “Notei diferenças, poderia me explicar?”       | Explicar seu ponto, sem se defender agressivamente  |
| Feedback brusco          | **P** → “Gostaria de confirmar detalhes para melhorar” | Pedido de orientação, ação positiva                 |
| Sarcasmo / ironia        | **R + F** → “Entendi sua frustração, vou revisar”      | Reconhecer emoção do outro + focar no fato          |

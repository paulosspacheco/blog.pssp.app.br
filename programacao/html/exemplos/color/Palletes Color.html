Console Virtual Gráfico

Simulador de API Windows Console com Múltiplas Paletas de Cores

Console inicializado. Digite 'help' para ver os comandos disponíveis.
>> Bem-vindo ao Console Virtual Gráfico
>> Este console suporta múltiplas paletas de cores
>> Use os botões abaixo para alternar entre as paletas
>> Paleta atual: Windows Console (padrão)
>> help
Comandos disponíveis:
- clear: Limpa o console
- info: Exibe informações do sistema
- theme [nome]: Altera o tema de cores
- help: Exibe esta ajuda

Instruções de Uso

  • Selecione uma paleta de cores clicando em um dos botões acima
  • Cada paleta contém 16 cores que combinam entre si
  • As cores de 0 a 7 são tons escuros (ideais para fundo)
  • As cores de 8 a 15 são tons claros (ideais para texto em temas escuros)
  • Use as paletas para personalizar a aparência do seu console virtual
